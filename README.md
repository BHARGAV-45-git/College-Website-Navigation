
# College Website Navigation Using React Router

**Name:** BHARGAV KADAVAKOLLU
**ID:** 2500030087

## Project Description

1. This project is a College Website developed using React and Vite.
2. React Router is used for navigation between different pages.
3. Link components are used to navigate between Home, About, Departments and Contact pages.
4. Reusable Navbar and Footer components are implemented.
5. This project demonstrates basic React components and routing concepts.

## Technologies Used
- React.js
- Vite
- React Router DOM
- HTML
- CSS
- JavaScript
